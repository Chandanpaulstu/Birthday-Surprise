## 📖 Quick Start Guide

### 1️⃣ Clone the Repository

Open your terminal and run:

```bash
git clone https://github.com/Chandanpaulstu/Birthday-Surprise.git
cd Birthday-Surprise
```

### 2️⃣ View the Project

Open `index.html` in your web browser to see the birthday surprise!

- Right-click on `index.html`
- Select "Open with" → Choose your browser
- Or drag and drop the file into your browser

### 3️⃣ Customize & Edit

Edit these files as needed:

- **`index.html`** - Change text, messages, and layout
- **`style.css`** - Update colors, fonts, and styling
- **`effect.js`** - Modify animations and effects
- **`cake.less`** - Customize cake styling

Save your changes and refresh the browser to see them!

## 🌍 Make Your Repo Public

### If you're using GitHub:

1. Go to [github.com](https://github.com)
2. Sign in to your account
3. Go to **Settings** → **Visibility**
4. Select **Public**
5. Save changes

Your repository is now visible to everyone!

### Push your changes:

```bash
git add .
git commit -m "Birthday surprise updates"
git push origin main
```
